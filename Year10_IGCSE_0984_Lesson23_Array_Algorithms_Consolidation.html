Learning objectives

  • Select and apply an appropriate array algorithm to a problem.
  • Trace linear search, maximum/minimum, Bubble Sort, totalling, counting and averaging.
  • Recognise the purpose of key variables such as Index, Found, Position, Temp, Total and Count.
  • Write clear Cambridge Pseudocode using arrays, iteration and selection.
Cambridge focus: This lesson consolidates the array algorithms studied in Lessons 16–22. It is a revision and application lesson, not an introduction to additional sorting or searching methods.

Reveal the answer

Temp stores one value temporarily so it is not overwritten during the swap.

2. Teacher review – 10 minutes

A. Linear search

Checks array elements one by one until the target is found or the end of the array is reached. The example below stops at the first occurrence.

Found ← FALSE
Index ← 1

WHILE Index <= 6 AND Found = FALSE
    IF Values[Index] = Target THEN
        Found ← TRUE
        Position ← Index
    ELSE
        Index ← Index + 1
    ENDIF
ENDWHILE

IF Found = TRUE THEN
    OUTPUT Position
ELSE
    OUTPUT "Not found"
ENDIF

B. Maximum and minimum

Initialise each result from the first element, then compare the remaining elements.

Maximum ← Values[1]
Minimum ← Values[1]

FOR Index ← 2 TO 6
    IF Values[Index] > Maximum THEN
        Maximum ← Values[Index]
    ENDIF
    IF Values[Index] < Minimum THEN
        Minimum ← Values[Index]
    ENDIF
NEXT Index

C. Bubble Sort – ascending order

Compare adjacent elements. Swap when the left value is greater than the right value.

FOR Pass ← 1 TO 5
    FOR Index ← 1 TO 6 - Pass
        IF Values[Index] > Values[Index + 1] THEN
            Temp ← Values[Index]
            Values[Index] ← Values[Index + 1]
            Values[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass

D. Totalling, counting and average

Total ← 0
Count ← 0

FOR Index ← 1 TO 6
    Total ← Total + Values[Index]
    IF Values[Index] >= 50 THEN
        Count ← Count + 1
    ENDIF
NEXT Index

Average ← Total / 6
Variable guide:
  • Index – current array position.
  • Target – value being searched for.
  • Found – Boolean flag indicating whether the target was found.
  • Position – index where the target was found.
  • Maximum / Minimum – current largest / smallest values.
  • Pass – current Bubble Sort pass; Temp – temporary value for swapping.
  • Total – running sum; Count – number of elements satisfying a condition.
Do not mix up the tasks: A linear search locates a value; it does not sort the array. Bubble Sort changes the order of the array. Totalling adds the actual values, while counting increases by one for each matching element.

4. Formal practice – 15 minutes

Attempt these integrated tasks using Cambridge Pseudocode. Show declarations, initialisation, loops, conditions and output.

  1. Class results: Input the scores of eight students into Scores[1:8]. Output the total, average, highest score and lowest score.
  2. Pass count: Using the same array, count and output how many students achieved a score of 50 or above.
  3. Search: Input a target score and use linear search to find its first occurrence. Output its position or a suitable message if it is not present.
  4. Sort: Write the Bubble Sort section to arrange the eight scores in ascending order. Use a temporary variable to swap adjacent values.
  5. Algorithm choice: For each task, state whether you would use linear search, Bubble Sort, maximum/minimum, totalling, counting or averaging. Give one sentence explaining your choice.
Sample solution framework – Questions 1 and 2 
DECLARE Scores : ARRAY[1:8] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
DECLARE Count : INTEGER
DECLARE Average : REAL
DECLARE Maximum : INTEGER
DECLARE Minimum : INTEGER

FOR Index ← 1 TO 8
    INPUT Scores[Index]
NEXT Index

Total ← 0
Count ← 0
Maximum ← Scores[1]
Minimum ← Scores[1]

FOR Index ← 1 TO 8
    Total ← Total + Scores[Index]

    IF Scores[Index] >= 50 THEN
        Count ← Count + 1
    ENDIF

    IF Scores[Index] > Maximum THEN
        Maximum ← Scores[Index]
    ENDIF

    IF Scores[Index] < Minimum THEN
        Minimum ← Scores[Index]
    ENDIF
NEXT Index

Average ← Total / 8

OUTPUT Total
OUTPUT Average
OUTPUT Maximum
OUTPUT Minimum
OUTPUT Count

This framework covers the calculations. Add the separate linear search and Bubble Sort sections when completing the other tasks.

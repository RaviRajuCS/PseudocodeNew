Lesson 7: Nested Selection

Cambridge IGCSE Computer Science 0984 · Making a decision inside another decision

50:00

Learning outcomes

  • Explain what nested selection means.
  • Identify an inner IF statement placed inside an outer IF branch.
  • Trace nested IF statements using different input values.
  • Write a nested selection algorithm with correct indentation and ENDIF placement.
  • Recognise when a nested decision is more suitable than one combined condition.
Prerequisite: You should already be confident with IF…THEN…ENDIF and IF…THEN…ELSE…ENDIF. A nested IF is simply a selection statement placed inside another selection statement.

2. Teacher demonstration – 10 minutes

What is nested selection?

Nested selection occurs when an IF statement is placed inside the THEN or ELSE part of another IF statement. The inner decision is reached only when the program follows the branch containing it.

IF <outer condition> THEN IF <inner condition> THEN <statements> ELSE <statements> ENDIF ELSE <statements> ENDIF

Worked example: Check eligibility

A student is eligible for a certificate if their mark is at least 50. Among students who pass, those with a mark of 80 or more receive a distinction.

INPUT Mark IF Mark >= 50 THEN IF Mark >= 80 THEN OUTPUT "Pass with distinction" ELSE OUTPUT "Pass" ENDIF ELSE OUTPUT "Not passed" ENDIF
Read the logic carefully: First the algorithm checks whether the student has passed. Only if that condition is TRUE does it check whether the mark is high enough for distinction.

Trace the example

MarkOuter condition Mark >= 50Inner condition Mark >= 80Output
42FALSENot evaluatedNot passed
65TRUEFALSEPass
88TRUETRUEPass with distinction

When the outer condition is FALSE, the inner IF is skipped. It is therefore correct to mark its condition “not evaluated” in the trace table.

Python equivalent

mark = int(input("Enter mark: ")) if mark >= 50: if mark >= 80: print("Pass with distinction") else: print("Pass") else: print("Not passed")

In Python, indentation identifies which IF a statement belongs to. In Cambridge Pseudocode, use indentation consistently and close each IF with its own ENDIF.

3. Interactive exploration – 10 minutes

Test the nested decision

Your trace will appear here.

Understand the decision path

Step 1 – Outer IF

Is Mark at least 50?

If FALSE, output “Not passed”. The inner IF is skipped.

Step 2 – Inner IF

This step is reached only if the outer condition is TRUE.

Is Mark at least 80?

Step 3 – Final output

TRUE gives “Pass with distinction”. FALSE gives “Pass”.

Important distinction: Nested selection is not the same as using AND. The inner condition is evaluated only after the outer condition has been satisfied. This can make the decision sequence clearer when the second test depends on the first.

4. Formal practice – 15 minutes

Write each solution in Cambridge Pseudocode. Pay attention to indentation and the number and position of ENDIF statements.

Task 1 – Access check

Input a person's age. If the age is at least 13, check whether it is at least 16. Output "Senior access" if it is at least 16; otherwise output "Junior access". If the age is below 13, output "Access not permitted".

INPUT Age IF Age >= 13 THEN IF Age >= 16 THEN OUTPUT "Senior access" ELSE OUTPUT "Junior access" ENDIF ELSE OUTPUT "Access not permitted" ENDIF

Task 2 – Delivery charge

Input an order total. If the total is at least 100, check whether it is at least 200. Output "Free delivery" for totals of 200 or more, and "Discounted delivery" for totals from 100 to below 200. If the total is below 100, output "Standard delivery charge".

INPUT OrderTotal IF OrderTotal >= 100 THEN IF OrderTotal >= 200 THEN OUTPUT "Free delivery" ELSE OUTPUT "Discounted delivery" ENDIF ELSE OUTPUT "Standard delivery charge" ENDIF

Task 3 – Password and account status

Input whether the password is correct as a BOOLEAN value, then input whether the account is active as a BOOLEAN value. If the password is correct, check whether the account is active. Output "Login successful" if both checks pass, or "Account inactive" if the account is not active. If the password is incorrect, output "Incorrect password".

DECLARE PasswordCorrect : BOOLEAN DECLARE AccountActive : BOOLEAN INPUT PasswordCorrect INPUT AccountActive IF PasswordCorrect = TRUE THEN IF AccountActive = TRUE THEN OUTPUT "Login successful" ELSE OUTPUT "Account inactive" ENDIF ELSE OUTPUT "Incorrect password" ENDIF

Attempt each task before revealing the suggested answer. Equivalent correct algorithms are acceptable.

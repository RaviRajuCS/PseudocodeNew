1. Recall — The three iteration structures

FOR…NEXT

Use when the number of repetitions is known or controlled by a counting variable.

FOR Count ← 1 TO 5
    OUTPUT Count
NEXT Count

WHILE…DO

Use when repetition continues while a condition is TRUE. The condition is checked first.

WHILE Count <= 5 DO
    OUTPUT Count
    Count ← Count + 1
ENDWHILE

REPEAT…UNTIL

Use when the body must execute before the stopping condition is checked.

REPEAT
    OUTPUT Count
    Count ← Count + 1
UNTIL Count > 5

2. Teacher demonstration — How do I choose?

Problem wording / requirementSuitable structureReason
Repeat exactly 20 times.FOR…NEXTThe number of repetitions is known.
Continue while the balance is greater than zero.WHILE…DOThe condition is checked before each pass; zero passes are possible.
Ask the user to enter a password at least once, then stop when it is correct.REPEAT…UNTILThe input must happen before the stopping condition can be checked.
Process each of the 30 values in a fixed data set.FOR…NEXTThere are 30 known items to process.

Worked example — Total of five entered values

The program must input exactly five values and output their total. The number of repetitions is known, so FOR…NEXT is a natural choice.

DECLARE Number : INTEGER
DECLARE Total : INTEGER
DECLARE Count : INTEGER

Total ← 0

FOR Count ← 1 TO 5
    INPUT Number
    Total ← Total + Number
NEXT Count

OUTPUT Total

5. Formal practice — Cambridge-style programming problems

Write complete solutions in Cambridge pseudocode. Use suitable declarations, initial values, input/output statements and iteration structures.

  1. Known repetitions: Write an algorithm to input 8 examination marks and output the total of the marks.
  2. Condition-controlled repetition: A variable Balance is initialised to 100. While the balance is greater than 20, subtract 15. Output the final balance.
  3. Post-condition repetition: Write an algorithm that asks a user to enter a whole number between 1 and 10 inclusive. Continue asking until a valid number is entered, then output the accepted number.
  4. Counting and totalling: A program inputs exactly 10 examination marks. Use a loop to calculate and output the total and average mark. Assume marks are integers and the average may be a real value.
  5. Find the error: Explain why the following algorithm does not terminate normally. Rewrite it correctly so that it outputs 1 to 5.
Count ← 1
WHILE Count <= 5 DO
    OUTPUT Count
ENDWHILE
Show guidance and sample solutions

Question 1 — FOR…NEXT

DECLARE Mark : INTEGER
DECLARE Total : INTEGER
DECLARE Count : INTEGER

Total ← 0
FOR Count ← 1 TO 8
    INPUT Mark
    Total ← Total + Mark
NEXT Count
OUTPUT Total

Question 2 — WHILE…DO

DECLARE Balance : INTEGER
Balance ← 100

WHILE Balance > 20 DO
    Balance ← Balance - 15
ENDWHILE

OUTPUT Balance

Question 3 — REPEAT…UNTIL

DECLARE Number : INTEGER
REPEAT
    OUTPUT "Enter a number from 1 to 10"
    INPUT Number
UNTIL Number >= 1 AND Number <= 10
OUTPUT Number

Question 4 — FOR…NEXT, total and average

DECLARE Mark : INTEGER
DECLARE Total : INTEGER
DECLARE Average : REAL
DECLARE Count : INTEGER

Total ← 0
FOR Count ← 1 TO 10
    INPUT Mark
    Total ← Total + Mark
NEXT Count

Average ← Total / 10
OUTPUT Total
OUTPUT Average

Question 5 — Missing update

Count is never changed, so the condition Count <= 5 remains TRUE. This creates an infinite loop. Add an increment:

DECLARE Count : INTEGER
Count ← 1
WHILE Count <= 5 DO
    OUTPUT Count
    Count ← Count + 1
ENDWHILE

Lesson summary — Your iteration decision guide

  • FOR…NEXT: the number of repetitions is known or controlled by a counting variable.
  • WHILE…DO: test first; repeat while the condition is TRUE; zero passes are possible.
  • REPEAT…UNTIL: execute first; stop when the condition is TRUE; at least one pass occurs.
  • Use trace tables to follow variable values and condition tests.
  • Initialise counters and accumulators correctly.
  • Make sure every condition-controlled loop can reach its stopping condition.

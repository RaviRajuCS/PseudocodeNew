Learning objectives

  • Recognise which standard method is appropriate for a given problem.
  • Translate a scenario into inputs, processing and outputs.
  • Apply linear search, bubble sort, totalling, counting, maximum, minimum and average.
  • Combine more than one standard method in a single algorithm where required.
Cambridge syllabus boundary: The standard methods addressed here are linear search, bubble sort, totalling, counting, and finding maximum, minimum and average values. This lesson applies those methods in context; it does not introduce additional searching or sorting algorithms.

Calculate the sum of valuesTotalling
Find how many values satisfy a conditionCounting
Find the greatest / smallest valueMaximum / minimum
Find the arithmetic meanAverage = total ÷ number of values

Think: A teacher wants to know how many students scored at least 50, and also the class average. Which two methods are needed?

Reveal the answer

Counting (for scores at least 50) and totalling plus averaging (sum all scores, then divide by the number of scores).

2. Teacher session – 10 minutes

Scenario A – School examination results

A teacher enters the marks of 8 students into Marks[1:8]. The teacher needs the total, average, highest mark, lowest mark and number of students who passed (a pass is 50 or above).

Plan: input the data once, initialise the accumulator and counter, initialise maximum and minimum from the first value, then process the array.

DECLARE Marks : ARRAY[1:8] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
DECLARE PassCount : INTEGER
DECLARE Highest : INTEGER
DECLARE Lowest : INTEGER
DECLARE Average : REAL

FOR Index ← 1 TO 8
    INPUT Marks[Index]
NEXT Index

Total ← 0
PassCount ← 0
Highest ← Marks[1]
Lowest ← Marks[1]

FOR Index ← 1 TO 8
    Total ← Total + Marks[Index]

    IF Marks[Index] >= 50 THEN
        PassCount ← PassCount + 1
    ENDIF

    IF Marks[Index] > Highest THEN
        Highest ← Marks[Index]
    ENDIF

    IF Marks[Index] < Lowest THEN
        Lowest ← Marks[Index]
    ENDIF
NEXT Index

Average ← Total / 8

OUTPUT Total
OUTPUT Average
OUTPUT Highest
OUTPUT Lowest
OUTPUT PassCount
Why this is efficient: One traversal of the array can update the total, pass counter, highest and lowest values. The average is calculated after the total is known.

Scenario B – Find a product code

A shop stores six product codes in an array. A user enters a code to look for. Use linear search to find the first matching position.

Found ← FALSE
Index ← 1

WHILE Index <= 6 AND Found = FALSE
    IF ProductCode[Index] = SearchCode THEN
        Found ← TRUE
        Position ← Index
    ELSE
        Index ← Index + 1
    ENDIF
ENDWHILE

IF Found = TRUE THEN
    OUTPUT "Code found at position ", Position
ELSE
    OUTPUT "Code not found"
ENDIF

Scenario C – Arrange prices

A shop wants six prices displayed from lowest to highest. Bubble sort compares adjacent values and swaps a pair when the left value is greater.

FOR Pass ← 1 TO 5
    FOR Index ← 1 TO 6 - Pass
        IF Price[Index] > Price[Index + 1] THEN
            Temp ← Price[Index]
            Price[Index] ← Price[Index + 1]
            Price[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass
Exam technique: Underline the task words in the question: “locate” suggests search; “arrange/order” suggests sort; “sum/total” suggests totalling; “how many” suggests counting; “greatest/highest” or “smallest/lowest” suggests maximum/minimum; “mean/average” suggests total divided by the number of values.

4. Formal practice – 15 minutes

For each scenario, identify the required standard method(s), then write Cambridge Pseudocode. Declare variables and initialise them correctly.

  1. Library borrowing: An array stores the number of books borrowed by 10 students. Input the values and output the total number of books borrowed and the average number per student.
  2. Sports results: An array stores the scores of 12 competitors. Find and output the highest and lowest scores, and count how many scores are at least 75.
  3. Inventory lookup: An array stores eight stock identification numbers. Input a required identification number and use linear search to output the first matching position, or “Not found”.
  4. Arrange temperatures: An array stores seven daily temperatures. Use Bubble Sort to arrange them in ascending order and output the sorted array.
  5. Combined school report: Input six assessment marks. Output the total, average, highest, lowest, number of marks at least 50, and whether a teacher-entered target mark is present. Use a suitable standard method for each requirement.

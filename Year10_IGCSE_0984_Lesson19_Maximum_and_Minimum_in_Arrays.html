Learning objectives

By the end of this lesson, you should be able to:

  • Explain what maximum and minimum values mean in an array.
  • Use a suitable initial value before comparing array elements.
  • Traverse an array and update maximum and minimum values.
  • Trace the algorithm accurately using a trace table.
Cambridge focus: Finding maximum and minimum values is one of the standard methods of solution named in the 0984 syllabus. This lesson concentrates on that required algorithmic skill.

2. Teacher session – 10 minutes

What are maximum and minimum values?

The maximum is the greatest value stored in an array. The minimum is the smallest value stored in an array. To find them, examine the elements one by one and update the stored result whenever a more suitable value is found.

Worked example: find both values

Assume the array contains six integer temperatures. First, input all six values. Then use the first element as the starting maximum and minimum.

DECLARE Temperatures : ARRAY[1:6] OF INTEGER
DECLARE Index : INTEGER
DECLARE Maximum : INTEGER
DECLARE Minimum : INTEGER

FOR Index ← 1 TO 6
    INPUT Temperatures[Index]
NEXT Index

Maximum ← Temperatures[1]
Minimum ← Temperatures[1]

FOR Index ← 2 TO 6
    IF Temperatures[Index] > Maximum THEN
        Maximum ← Temperatures[Index]
    ENDIF

    IF Temperatures[Index] < Minimum THEN
        Minimum ← Temperatures[Index]
    ENDIF
NEXT Index

OUTPUT "Maximum value: ", Maximum
OUTPUT "Minimum value: ", Minimum
Why start with the first array element? It gives us a real value from the data. Do not automatically initialise the maximum or minimum to zero. If every value is negative, starting at zero can produce an incorrect result.

Finding only one value

For maximum only, initialise Maximum ← Values[1], then compare elements from index 2 onwards. For minimum only, use the same approach with Minimum and the less-than operator.

Important: This example assumes the array contains at least one element. The first element is accessed to initialise both variables, so an empty array would not be suitable.

Python equivalent (supporting comparison)

temperatures = []

for index in range(6):
    value = int(input("Enter a temperature: "))
    temperatures.append(value)

maximum = temperatures[0]
minimum = temperatures[0]

for index in range(1, 6):
    if temperatures[index] > maximum:
        maximum = temperatures[index]
    if temperatures[index] < minimum:
        minimum = temperatures[index]

print("Maximum value:", maximum)
print("Minimum value:", minimum)

4. Formal practice – 15 minutes

Write Cambridge Pseudocode for each task. Use a suitable array traversal and initialise the comparison variable from the first element.

  1. Maximum: An array TestScores[1:8] stores eight test scores. Input the scores and output the highest score.
  2. Minimum: An array DailyRainfall[1:7] stores rainfall measurements for seven days. Input the values and output the lowest measurement.
  3. Both values: An array Heights[1:10] stores ten students’ heights in centimetres. Input the values and output both the tallest and shortest heights.
  4. Negative values: An array Balances[1:5] stores five integer account adjustments. The values may be negative or positive. Find and output the maximum and minimum values.
  5. Trace: Trace the maximum-only algorithm for Scores = [18, 22, 15, 30, 27]. Show the value of Maximum after each comparison.
Check your approach – sample solution for Question 3 
DECLARE Heights : ARRAY[1:10] OF INTEGER
DECLARE Index : INTEGER
DECLARE Tallest : INTEGER
DECLARE Shortest : INTEGER

FOR Index ← 1 TO 10
    INPUT Heights[Index]
NEXT Index

Tallest ← Heights[1]
Shortest ← Heights[1]

FOR Index ← 2 TO 10
    IF Heights[Index] > Tallest THEN
        Tallest ← Heights[Index]
    ENDIF
    IF Heights[Index] < Shortest THEN
        Shortest ← Heights[Index]
    ENDIF
NEXT Index

OUTPUT Tallest
OUTPUT Shortest

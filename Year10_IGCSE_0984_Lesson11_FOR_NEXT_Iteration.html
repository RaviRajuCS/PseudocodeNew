Lesson 11: FOR…NEXT – Count-Controlled Iteration

Cambridge IGCSE Computer Science 0984 · Repeating instructions a specified number of times

50:00
50 minutesCount-controlled loopCambridge Pseudocode

Learning outcomes

  • Explain when a count-controlled loop is appropriate.
  • Write the Cambridge FOR…TO…NEXT structure correctly.
  • Use a loop control variable of type INTEGER.
  • Trace the values taken by the loop control variable.
  • Use STEP for increments, including negative increments.
  • Compare Cambridge Pseudocode with Python's for and range().
Today's focus: FOR…NEXT is suitable when the number of repetitions is known or controlled by a start and end value. We will not introduce WHILE or REPEAT in this lesson.

2. Teacher demonstration – 10 minutes

Cambridge FOR…NEXT syntax

FOR <identifier> ← <value1> TO <value2> <statements> NEXT <identifier>

The loop control variable is assigned each integer value from value1 to value2, inclusive. The statements inside the loop execute after each assignment.

Worked example 1 – Display 1 to 5

FOR Count ← 1 TO 5 OUTPUT Count NEXT Count

Important Cambridge rules:
  • The loop control identifier must be an INTEGER variable.
  • The start and end values must be expressions that evaluate to integers.
  • The start and end values are both included.
  • If start = end, the statements execute once.
  • If start > end, the statements do not execute.

Using STEP

FOR Number ← 2 TO 10 STEP 2 OUTPUT Number NEXT Number

Output: 2, 4, 6, 8, 10. The increment is 2.

A negative increment can count down:

FOR Number ← 5 TO 1 STEP -1 OUTPUT Number NEXT Number

Output: 5, 4, 3, 2, 1. The loop stops when the next value would go past the end value.

Python comparison

# Cambridge: FOR Count ← 1 TO 5 for count in range(1, 6): print(count) # Cambridge: FOR Number ← 5 TO 1 STEP -1 for number in range(5, 0, -1): print(number)
Python difference: The final value in range() is excluded. Therefore, to include 5 in Python's range(1, 6), the stop value is 6. Cambridge FOR…TO includes its end value when the loop reaches it.

3. Interactive exploration – 10 minutes

FOR loop simulator

Set the values and run the simulator. Use integer values.

Try these tests:

  • Start 1, end 5, step 1.
  • Start 2, end 10, step 2.
  • Start 5, end 1, step -1.
  • Start 4, end 4, step 1.
  • Start 7, end 3, step 1.
The increment must move the loop control variable towards the end value. If it moves away from the end value, the loop may not terminate. The simulator limits the number of generated values to protect the browser.

4. Formal practice – 15 minutes

Write each solution using Cambridge Pseudocode. Remember the assignment arrow, inclusive end value and matching loop identifier after NEXT.

Task 1 – Display even numbers

Use a FOR loop to display the even numbers from 2 to 20.

FOR Number ← 2 TO 20 STEP 2 OUTPUT Number NEXT Number

Task 2 – Calculate a total

Use a FOR loop to calculate and display the total of the integers from 1 to 10.

Total ← 0 FOR Number ← 1 TO 10 Total ← Total + Number NEXT Number OUTPUT Total

Task 3 – Input five temperatures

Input five temperature readings. Calculate and display their total. Do not calculate the average yet.

Total ← 0 FOR Count ← 1 TO 5 INPUT Temperature Total ← Total + Temperature NEXT Count OUTPUT Total

Task 4 – Countdown

Use a FOR loop to display the integers from 10 down to 1.

FOR Number ← 10 TO 1 STEP -1 OUTPUT Number NEXT Number

Attempt each task before revealing the suggested answer. The simulator and answers are practice aids; write your final algorithms independently.

Teacher checkpoint

  • Students know the control variable must be INTEGER.
  • Students understand that the start and end values are inclusive.
  • Students can dry-run the loop and record each value of the control variable.
  • Students use STEP correctly for increasing and decreasing sequences.
  • Students understand the difference between Cambridge's inclusive end value and Python's exclusive range stop value.

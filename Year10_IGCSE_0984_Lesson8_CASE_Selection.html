Lesson 8: CASE Selection

Cambridge IGCSE Computer Science 0984 · Selecting from several possible alternatives

50:00
50 minutesCASE OFPseudocode first

Learning outcomes

  • Explain when CASE selection is useful.
  • Recognise the structure of a Cambridge CASE statement.
  • Use CASE OF to select a branch according to the value of an identifier.
  • Use OTHERWISE for values that do not match a listed case.
  • Trace and write simple CASE algorithms accurately.
Lesson boundary: This lesson focuses on simple CASE selection. It does not introduce iteration or combine CASE with loops.

2. Teacher demonstration – 10 minutes

Why use CASE?

Suppose a program must display a different message for each of several menu choices. A long chain of IF…ELSE statements could be written, but CASE provides a clear structure when one identifier is compared with several possible values.

Cambridge Pseudocode structure

CASE OF <identifier> <value 1> : <statements> <value 2> : <statements> <value 3> : <statements> OTHERWISE : <statements> ENDCASE
Read the structure: The identifier is evaluated. The statements associated with the matching value are executed. If none of the listed values matches, the OTHERWISE branch is executed. ENDCASE closes the CASE structure.

Worked example: Menu choice

INPUT Choice CASE OF Choice 1 : OUTPUT "Add a record" 2 : OUTPUT "Display records" 3 : OUTPUT "Search records" OTHERWISE : OUTPUT "Invalid choice" ENDCASE

If Choice is 2, the program outputs “Display records”. If Choice is 5, no listed value matches, so the OTHERWISE branch outputs “Invalid choice”.

Python equivalent (comparison)

choice = int(input("Enter choice: ")) if choice == 1: print("Add a record") elif choice == 2: print("Display records") elif choice == 3: print("Search records") else: print("Invalid choice")

Python's if/elif/else can represent this decision pattern. It is a Python comparison, not Cambridge Pseudocode syntax.

Important points

  • Write CASE OF followed by the identifier being tested.
  • Each case value is followed by a colon.
  • OTHERWISE handles values not listed in the CASE branches.
  • ENDCASE closes the structure.
  • Use CASE when selecting between several alternatives based on the value of one identifier.

4. Formal practice – 15 minutes

Write each solution using Cambridge Pseudocode. Use CASE OF, a colon after each case value, OTHERWISE where appropriate, and ENDCASE.

Task 1 – Day number

Input an integer DayNumber. Use CASE to output the day name for values 1 to 5: Monday, Tuesday, Wednesday, Thursday and Friday. For any other value, output "Not a school day".

INPUT DayNumber CASE OF DayNumber 1 : OUTPUT "Monday" 2 : OUTPUT "Tuesday" 3 : OUTPUT "Wednesday" 4 : OUTPUT "Thursday" 5 : OUTPUT "Friday" OTHERWISE : OUTPUT "Not a school day" ENDCASE

Task 2 – Calculator operation

Input two numbers, Number1 and Number2, and an operation code. If the code is 1, output their sum. If it is 2, output Number1 minus Number2. If it is 3, output their product. For any other code, output "Invalid operation".

INPUT Number1 INPUT Number2 INPUT Operation CASE OF Operation 1 : OUTPUT Number1 + Number2 2 : OUTPUT Number1 - Number2 3 : OUTPUT Number1 * Number2 OTHERWISE : OUTPUT "Invalid operation" ENDCASE

Task 3 – Grade description

Input a grade character. Use CASE to output "Excellent" for A, "Very good" for B, "Good" for C, and "Needs improvement" for D. For any other character, output "Grade not recognised".

INPUT Grade CASE OF Grade "A" : OUTPUT "Excellent" "B" : OUTPUT "Very good" "C" : OUTPUT "Good" "D" : OUTPUT "Needs improvement" OTHERWISE : OUTPUT "Grade not recognised" ENDCASE

Attempt each task before revealing the suggested answer. These are practice questions; equivalent correct solutions are acceptable.

Teacher checkpoint

  • Students can explain why CASE may be clearer than a long chain of IF…ELSE statements for a multi-way choice.
  • Students write CASE OF followed by the correct identifier.
  • Students include a colon after each case value.
  • Students use OTHERWISE for unmatched values and ENDCASE to close the structure.
  • Students can trace the matching case for a given input.

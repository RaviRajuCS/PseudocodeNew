1. Recall — WHILE…DO

In Lesson 13, you learned that WHILE…DO checks its condition before executing the loop body.

WHILE <condition> DO
    <statements>
ENDWHILE
  • If the condition is TRUE, the body executes.
  • If the condition is FALSE, the body does not execute.
  • Therefore, a WHILE loop can execute zero times.

Question: What if the instructions must be carried out at least once before the condition can be checked?

For example, a program may need to ask a user to enter a value before it can decide whether another entry is required. REPEAT…UNTIL is suitable for this pattern.

2. Teacher demonstration — Cambridge REPEAT…UNTIL syntax

REPEAT
    <statements>
UNTIL <condition>
REPEAT
Begins the loop body.
Statements
These execute before the condition is tested.
UNTIL
Introduces the condition that ends the loop.
Condition
Must evaluate to a BOOLEAN value: TRUE or FALSE.

How the loop executes

  1. Execute the statements in the loop body.
  2. Evaluate the UNTIL condition.
  3. If the condition is TRUE, leave the loop.
  4. If the condition is FALSE, repeat the statements.
  5. Continue until the condition becomes TRUE.

Worked example 1 — Display numbers from 1 to 5

DECLARE Count : INTEGER
Count ← 1

REPEAT
    OUTPUT Count
    Count ← Count + 1
UNTIL Count > 5

Notice that the loop outputs the value and increases Count before checking whether Count is greater than 5.

PassCount before bodyOutputCount after incrementUNTIL Count > 5

3334FALSE — repeat

Worked example 2 — Keep asking until a valid mark is entered

Assume a valid mark is from 0 to 100 inclusive. The program must ask at least once.

DECLARE Mark : INTEGER

REPEAT
    OUTPUT "Enter a mark from 0 to 100"
    INPUT Mark
UNTIL Mark >= 0 AND Mark <= 100

OUTPUT "Accepted"

The loop ends only when the entered mark is within the valid range. If the mark is invalid, the condition is FALSE and the prompt is repeated.

Remember: In REPEAT…UNTIL, TRUE means stop; FALSE means repeat. This is the opposite way of thinking from the continuation condition in WHILE…DO.

3. WHILE…DO and REPEAT…UNTIL — compare carefully

FeatureWHILE…DOREPEAT…UNTIL

WHILE…DO
WHILE Count <= 5 DO
    OUTPUT Count
    Count ← Count + 1
ENDWHILE
REPEAT…UNTIL
REPEAT
    OUTPUT Count
    Count ← Count + 1
UNTIL Count > 5

Both examples can display the numbers 1 to 5 when Count is initially 1. However, their condition-testing positions and stopping-condition logic are different.

4. Python equivalent

Python does not have a direct REPEAT…UNTIL statement. A common way to implement the same behaviour is to use while True and a conditional exit. This is a Python comparison, not Cambridge pseudocode syntax.

count = 1

while True:
    print(count)
    count = count + 1
    if count > 5:
        break

The Python example uses break to leave the loop. Learn the Cambridge REPEAT…UNTIL structure first. Do not write break as a replacement for Cambridge pseudocode UNTIL.

6. Common errors to avoid

Error: Reversing the condition
UNTIL ends the loop when its condition is TRUE. Do not confuse this with WHILE.
Error: Testing too early
The statements execute before the UNTIL condition is evaluated.
Error: No progress
If the body never changes anything relevant to the condition, the loop may continue indefinitely.
Error: Assuming zero passes
REPEAT…UNTIL always executes its body at least once.

Trace the stopping condition

Value ← 10
REPEAT
    OUTPUT Value
    Value ← Value - 2
UNTIL Value < 5

Outputs: 10, 8, 6. After the third pass, Value becomes 4. The condition Value < 5 is TRUE, so the loop ends.

Lesson summary

  • REPEAT…UNTIL is a post-condition iteration structure.
  • The loop body executes before the condition is tested.
  • The condition must evaluate to BOOLEAN.
  • If the condition is TRUE, the loop ends.
  • If the condition is FALSE, the loop repeats.
  • The loop body always executes at least once.

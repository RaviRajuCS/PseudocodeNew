Lesson 9: Selection Statements – Consolidation

Cambridge IGCSE Computer Science 0984 · Choosing and applying the appropriate selection structure

50:00
50 minutesRevision and applicationPseudocode

Learning outcomes

  • Distinguish between simple IF, IF…ELSE, nested IF and CASE.
  • Select an appropriate structure for a stated problem.
  • Trace selection algorithms, including boundary values.
  • Identify and correct common selection errors.
  • Write complete Cambridge Pseudocode solutions.
Today's focus: This is a consolidation lesson. No new selection construct is introduced. Concentrate on choosing the right structure and using it accurately.

1. Recall – 5 minutes

Match each situation to the most suitable structure.

1. Display “Adult” only when Age is at least 18; otherwise do nothing.
2. Display “Pass” or “Fail” depending on whether Mark is at least 50.
3. Select one of five menu actions based on a menu number.

2. Teacher demonstration – 10 minutes

Compare the four selection patterns

1. Simple IF

Use when an action is needed only if a condition is TRUE.

IF Age >= 18 THEN OUTPUT "Adult" ENDIF
2. IF…ELSE

Use when one of two alternative actions must be selected.

IF Mark >= 50 THEN OUTPUT "Pass" ELSE OUTPUT "Fail" ENDIF
3. Nested IF

Use when a second decision is made within a branch of a first decision.

IF Mark >= 50 THEN IF Mark >= 80 THEN OUTPUT "Distinction" ELSE OUTPUT "Pass" ENDIF ELSE OUTPUT "Fail" ENDIF
4. CASE

Use when selecting from several alternatives based on the value of one identifier.

CASE OF Choice 1 : OUTPUT "Add" 2 : OUTPUT "Display" 3 : OUTPUT "Search" OTHERWISE : OUTPUT "Invalid" ENDCASE

Decision guide

Question to askSuitable structure
Is an action required only when one condition is TRUE?Simple IF
Must the algorithm choose between two outcomes?IF…ELSE
Does a second decision depend on the result of a first decision?Nested IF
Must one of several listed values be selected?CASE
Exam tip: Do not choose a structure simply because it looks shorter. Choose one that represents the conditions in the question clearly and produces every required outcome.

3. Interactive exploration – 10 minutes

Choose the best selection structure

Read each problem and choose the structure you would use. Then check your reasoning.

Scenario A: If a temperature is above 35, display “Heat warning”. No message is needed otherwise.

Scenario B: A program must display “Positive” or “Not positive” depending on a number.

Scenario C: A customer first qualifies for a discount if their purchase is at least 100. If qualified, check whether the purchase is at least 250 to decide the discount level.

Scenario D: A user enters a code from 1 to 4 to select one of four report types.

Trace the boundary values

For the algorithm below, test marks of 49, 50 and 80.

IF Mark >= 50 THEN IF Mark >= 80 THEN OUTPUT "Distinction" ELSE OUTPUT "Pass" ENDIF ELSE OUTPUT "Fail" ENDIF

4. Formal practice – 15 minutes

Write the most appropriate Cambridge Pseudocode solution for each task. State the selection structure you chose.

Task 1 – Simple IF

Input the number of books borrowed. If the number is greater than 5, output "Please return a book". If it is 5 or fewer, no message is required.

INPUT BooksBorrowed IF BooksBorrowed > 5 THEN OUTPUT "Please return a book" ENDIF

Task 2 – IF…ELSE

Input a whole number. Output "Multiple of 5" if the number is divisible by 5; otherwise output "Not a multiple of 5". Use MOD.

INPUT Number IF MOD(Number, 5) = 0 THEN OUTPUT "Multiple of 5" ELSE OUTPUT "Not a multiple of 5" ENDIF

Task 3 – Nested IF

Input a student's attendance percentage. If attendance is at least 75, check whether it is at least 90. Output "Excellent attendance" for 90 or above, or "Attendance accepted" for 75 to below 90. Otherwise output "Attendance below requirement".

INPUT Attendance IF Attendance >= 75 THEN IF Attendance >= 90 THEN OUTPUT "Excellent attendance" ELSE OUTPUT "Attendance accepted" ENDIF ELSE OUTPUT "Attendance below requirement" ENDIF

Task 4 – CASE

Input a transport code. Use CASE to output "Bus" for 1, "Train" for 2, "Metro" for 3 and "Taxi" for 4. For any other value, output "Unknown transport".

INPUT TransportCode CASE OF TransportCode 1 : OUTPUT "Bus" 2 : OUTPUT "Train" 3 : OUTPUT "Metro" 4 : OUTPUT "Taxi" OTHERWISE : OUTPUT "Unknown transport" ENDCASE

Attempt each problem independently before revealing the suggested answer. Other correct algorithms may also be accepted.

5. Assessment and feedback – 10 minutes

Enter your full name and answer all six questions.

1. Which structure is suitable when an action is required only if a condition is TRUE?
2. Which structure provides two alternative branches?
3. In nested selection, when is the inner IF reached?
4. Which structure is designed for selecting between several listed values of one identifier?
5. What is output when Mark = 80 in the nested example in this lesson?
6. What is the purpose of OTHERWISE in CASE?

Teacher checkpoint

  • Students can justify their choice of selection structure.
  • Students correctly use THEN, ELSE, ENDIF, CASE OF, OTHERWISE and ENDCASE.
  • Students trace both TRUE and FALSE paths.
  • Students test boundary values, not just typical values.
  • Students produce complete algorithms with correct indentation.

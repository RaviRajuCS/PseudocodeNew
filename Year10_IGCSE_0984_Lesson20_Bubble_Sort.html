Quick question: If two adjacent values are 18 and 7, which value should come first in ascending order?

Reveal the answer

7 should come before 18. Since 18 is currently on the left and is greater than 7, the two values must be swapped.

2. Teacher session – 10 minutes

What is sorting?

Sorting means arranging data into a particular order. In this lesson, we arrange integer values in ascending order – from the smallest to the largest.

How Bubble Sort works

Bubble Sort repeatedly compares adjacent pairs of elements. If the left value is greater than the right value, the values are swapped. At the end of each complete pass, the largest value that has not already reached its final position will have moved to the right-hand end of the unsorted section.

Remember the rule for ascending order: If Array[Index] > Array[Index + 1], swap the two values. If the left value is smaller or equal, leave them in place.

Example: sort six values

Starting array: 29, 10, 14, 37, 13, 5

Pass 1 – compare adjacent values from left to right:

29, 10 → swap
29, 14 → swap
29, 37 → no swap
37, 13 → swap
37, 5 → swap

After Pass 1: 10, 14, 29, 13, 5, 37. The largest value, 37, is now in its final position.

Pass 2: compare only the first five positions. After Pass 2: 10, 14, 13, 5, 29, 37.

Pass 3: compare the first four positions. After Pass 3: 10, 13, 5, 14, 29, 37.

Pass 4: compare the first three positions. After Pass 4: 10, 5, 13, 14, 29, 37.

Pass 5: compare the first two positions. After Pass 5: 5, 10, 13, 14, 29, 37.

Swapping two values

A temporary variable is needed so that neither value is lost during the exchange.

Temp ← Array[Index]
Array[Index] ← Array[Index + 1]
Array[Index + 1] ← Temp

Complete Cambridge Pseudocode – ascending Bubble Sort

DECLARE Values : ARRAY[1:6] OF INTEGER
DECLARE Pass : INTEGER
DECLARE Index : INTEGER
DECLARE Temp : INTEGER

FOR Index ← 1 TO 6
    INPUT Values[Index]
NEXT Index

FOR Pass ← 1 TO 5
    FOR Index ← 1 TO 6 - Pass
        IF Values[Index] > Values[Index + 1] THEN
            Temp ← Values[Index]
            Values[Index] ← Values[Index + 1]
            Values[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass

FOR Index ← 1 TO 6
    OUTPUT Values[Index]
NEXT Index
Why does the inner loop get shorter? After each pass, one more largest value is in its final position at the right-hand end. There is no need to compare that finalised position again.
Common mistake: Do not swap when the left value is smaller. For ascending order, the comparison is >. Using < would move the algorithm towards descending order.

Python equivalent (supporting comparison)

values = []

for index in range(6):
    values.append(int(input("Enter an integer: ")))

for pass_number in range(5):
    for index in range(5 - pass_number):
        if values[index] > values[index + 1]:
            temp = values[index]
            values[index] = values[index + 1]
            values[index + 1] = temp

print(values)

4. Formal practice – 15 minutes

Write Cambridge Pseudocode for each task. Use adjacent comparisons and a temporary variable to swap values.

  1. Five numbers: Input five integer values into an array and use Bubble Sort to output them in ascending order.
  2. Trace: Trace the first two passes of Bubble Sort for [16, 9, 21, 4, 12]. Show the array after each pass.
  3. Identify the error: A student uses IF Values[Index] < Values[Index + 1] THEN before swapping. Explain why this does not produce ascending order.
  4. Adapt the algorithm: Change the number of elements in the given six-element algorithm to eight. State the correct number of outer passes and the inner-loop range for each pass.
  5. Explain: Why is a temporary variable required when swapping two array elements? Explain what could go wrong if the first value is overwritten before it is saved.
Check your approach – sample solution for Question 1 
DECLARE Numbers : ARRAY[1:5] OF INTEGER
DECLARE Pass : INTEGER
DECLARE Index : INTEGER
DECLARE Temp : INTEGER

FOR Index ← 1 TO 5
    INPUT Numbers[Index]
NEXT Index

FOR Pass ← 1 TO 4
    FOR Index ← 1 TO 5 - Pass
        IF Numbers[Index] > Numbers[Index + 1] THEN
            Temp ← Numbers[Index]
            Numbers[Index] ← Numbers[Index + 1]
            Numbers[Index + 1] ← Temp
        ENDIF
    NEXT Index
NEXT Pass

FOR Index ← 1 TO 5
    OUTPUT Numbers[Index]
NEXT Index

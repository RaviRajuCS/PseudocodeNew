1. Recall — What do we already know?

  1. Iteration means repeating a set of statements.
  2. A FOR…NEXT loop is useful when the number of repetitions is known or controlled by a counter.
  3. A loop needs a clear stopping point.

Think: What if we do not know in advance how many repetitions are needed, but we know the condition that should keep the repetition going?

That is one situation in which a WHILE loop is useful.

2. Teacher demonstration — Cambridge WHILE…DO syntax

WHILE <condition> DO
    <statements>
ENDWHILE
WHILE
Begins the loop and introduces the condition.
Condition
Must evaluate to a BOOLEAN value: TRUE or FALSE.
DO
Marks the beginning of the statements to be repeated.
ENDWHILE
Marks the end of the loop body. The condition is checked again.

How the loop executes

  1. Evaluate the condition.
  2. If it is FALSE, leave the loop. The body is not executed.
  3. If it is TRUE, execute the statements in the loop body.
  4. Return to the condition and test it again.
  5. Continue until the condition becomes FALSE.

Worked example 1 — Display numbers from 1 to 5

DECLARE Count : INTEGER
Count ← 1

WHILE Count <= 5 DO
    OUTPUT Count
    Count ← Count + 1
ENDWHILE

The loop body displays the current value and then increases Count by 1. Eventually Count becomes 6, so the condition Count <= 5 is FALSE and the loop stops.

Worked example 2 — Repeated subtraction

This follows the style of the Cambridge syllabus example. Keep subtracting 9 while the number is greater than 9.

DECLARE Number : INTEGER
Number ← 50

WHILE Number > 9 DO
    Number ← Number - 9
ENDWHILE

OUTPUT Number

Values after each pass: 41, 32, 23, 14, 5. The next condition test is 5 > 9, which is FALSE. The output is 5.

Important: The condition is checked before each pass. If it is FALSE at the first test, the loop body runs zero times.

3. Python equivalent

5. Common errors to avoid

Error: No update
If the condition remains TRUE and nothing changes it, the loop may never end.
Error: Wrong condition
Check whether the loop should continue while a condition is TRUE or stop when it becomes FALSE.
Error: Wrong initial value
Set the starting value before the WHILE statement.
Error: Assuming one pass
The condition is tested first, so the loop might run zero times.

Infinite loop example

Count ← 1
WHILE Count <= 5 DO
    OUTPUT Count
    // Count is never increased
ENDWHILE

This condition remains TRUE because Count stays at 1. Always check that the loop body changes something that can eventually make the condition FALSE.

Lesson summary

  • WHILE…DO is a pre-condition iteration structure.
  • The condition must evaluate to TRUE or FALSE.
  • The condition is tested before the body executes.
  • The body repeats while the condition is TRUE.
  • The body may execute zero times.
  • Make sure that the loop can eventually reach a FALSE condition.

1. Recall — Declaring a one-dimensional array

In Lesson 16, we declared an array using its identifier, index range and data type.

DECLARE Scores : ARRAY[1:5] OF INTEGER

This declaration reserves five INTEGER elements. Their indexes are 1, 2, 3, 4 and 5.

Scores[1]?
Scores[2]?
Scores[3]?
Scores[4]?
Scores[5]?

The question marks represent elements whose values have not yet been entered in our example.

2. Teacher demonstration — Populating an array

Populating an array means entering or assigning data to its elements.

Method A: Assigning values individually

Scores[1] ← 72
Scores[2] ← 85
Scores[3] ← 64
Scores[4] ← 91
Scores[5] ← 78

This works for a small array, but it is repetitive. A loop allows the same input operation to be carried out for every index.

Method B: Using FOR…NEXT to input all elements

DECLARE Scores : ARRAY[1:5] OF INTEGER
DECLARE Index : INTEGER

FOR Index ← 1 TO 5
    INPUT Scores[Index]
NEXT Index

What happens?

  1. Index starts at 1.
  2. The program inputs a value into Scores[1].
  3. Index increases to 2 and the program inputs Scores[2].
  4. The same process continues until Scores[5] has received a value.
  5. The FOR loop finishes after the final index has been processed.

Method C: Output every element

FOR Index ← 1 TO 5
    OUTPUT Scores[Index]
NEXT Index

This visits each array element in index order and displays its stored value.

Important: Scores[Index] means the element at the current index. As Index changes, the element being accessed changes.

3. Teacher demonstration — Traversing and processing

Traversing means visiting each element. While visiting the elements, the program can perform a calculation.

Worked example — Calculate the total of five scores

DECLARE Scores : ARRAY[1:5] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER

Total ← 0

FOR Index ← 1 TO 5
    INPUT Scores[Index]
    Total ← Total + Scores[Index]
NEXT Index

OUTPUT Total

The total is initialised to 0 before the loop. Each newly entered array element is added to the running total.

Worked example — Calculate the average

DECLARE Scores : ARRAY[1:5] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
DECLARE Average : REAL

Total ← 0

FOR Index ← 1 TO 5
    INPUT Scores[Index]
    Total ← Total + Scores[Index]
NEXT Index

Average ← Total / 5
OUTPUT Average

For the same five values, the average is 78.

5. Common errors to avoid

Wrong index range
If the array is declared ARRAY[1:5], the traversal should normally use indexes 1 to 5.
Wrong element reference
Use Scores[Index], not simply Scores, when referring to one element.
Total not initialised
Set Total ← 0 before adding the values.
Off-by-one error
Check the first and last index. Do not accidentally omit an element or access beyond the array bounds.

Compare these two statements

OUTPUT Scores[Index]

Outputs the value stored at the current array index.

OUTPUT Index

Outputs the index number itself, not the stored array value.

Lesson summary

  • Populating means entering or assigning values to array elements.
  • Traversing means visiting elements one by one.
  • Use a FOR…NEXT loop to process the known array index range.
  • Use ArrayName[Index] to access the current element.
  • Initialise accumulators before the loop.
  • Check that the loop bounds match the declared array bounds.

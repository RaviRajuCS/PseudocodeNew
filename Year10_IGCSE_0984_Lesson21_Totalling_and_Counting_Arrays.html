2. Teacher session – 10 minutes

A. Totalling – finding the sum

Totalling means adding values together to calculate a sum. A variable used to keep a running total is called an accumulator.

Essential rule: Initialise the accumulator to zero before adding the array elements. Otherwise, the total may include an unwanted starting value.

Example: input six test scores and calculate their total.

DECLARE Scores : ARRAY[1:6] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER

Total ← 0

FOR Index ← 1 TO 6
    INPUT Scores[Index]
NEXT Index

FOR Index ← 1 TO 6
    Total ← Total + Scores[Index]
NEXT Index

OUTPUT "Total score: ", Total

Trace the accumulator

Final total = 45. Each new value is added to the running total.

B. Counting – counting values that meet a condition

Counting means finding how many array elements satisfy a condition. A variable used to keep the number of matching elements is called a counter.

Essential rule: Initialise the counter to zero. Increase it by one only when an element meets the condition.

Example: count how many of six scores are at least 50.

DECLARE Scores : ARRAY[1:6] OF INTEGER
DECLARE Index : INTEGER
DECLARE Count : INTEGER

FOR Index ← 1 TO 6
    INPUT Scores[Index]
NEXT Index

Count ← 0

FOR Index ← 1 TO 6
    IF Scores[Index] >= 50 THEN
        Count ← Count + 1
    ENDIF
NEXT Index

OUTPUT "Number of scores at least 50: ", Count

For [42, 67, 50, 38, 81, 49], the matching values are 67, 50 and 81. Therefore, Count = 3.

Accumulator versus counter

Accumulator (totalling)Counter (counting)
Stores a running sumStores how many matches have occurred
Usually updated by adding the current valueUpdated by adding 1 when a condition is true
Total ← Total + Array[Index]Count ← Count + 1
Initial value: 0Initial value: 0

Python comparison

# Totalling
scores = [12, 8, 15, 10]
total = 0

for index in range(4):
    total = total + scores[index]

print("Total:", total)

# Counting scores of at least 50
scores = [42, 67, 50, 38, 81, 49]
count = 0

for index in range(6):
    if scores[index] >= 50:
        count = count + 1

print("Count:", count)

Cambridge Pseudocode is the primary language for this lesson. Python is included as a supporting comparison.

Common errors: Do not forget to initialise Total or Count to zero. Do not add one to the counter when the condition is false. Do not confuse adding the element’s value with counting one matching element.

Learning objectives

1. Recall – 5 minutes

Recall the previous lesson:

  • An accumulator stores a running total.
  • The accumulator is initialised to zero before adding values.
  • A FOR…NEXT loop can visit every array element.
  • The number of elements in an array can be identified from its declared bounds.

Quick question: The values are 6, 8 and 10. Their total is 24. How do you calculate their average?

Reveal the answer

Divide the total by the number of values: 24 ÷ 3 = 8.

2. Teacher session – 10 minutes

What is an average?

The arithmetic mean, commonly called the average, is calculated by adding all the values and dividing the total by how many values there are.

Formula:
Average = Total of all values ÷ Number of values

Worked example

Six students obtain the following scores: 12, 15, 10, 18, 14, 11.

  • Total = 12 + 15 + 10 + 18 + 14 + 11 = 80
  • Number of scores = 6
  • Average = 80 ÷ 6 = 13.333…

Cambridge Pseudocode – input values and calculate the average

DECLARE Scores : ARRAY[1:6] OF INTEGER
DECLARE Index : INTEGER
DECLARE Total : INTEGER
DECLARE Average : REAL

Total ← 0

FOR Index ← 1 TO 6
    INPUT Scores[Index]
NEXT Index

FOR Index ← 1 TO 6
    Total ← Total + Scores[Index]
NEXT Index

Average ← Total / 6

OUTPUT "Average score: ", Average
Important: The array has six elements, so the total is divided by 6. The variable Average is declared as REAL because the result may contain a fractional part.

Python comparison

scores = []

for index in range(6):
    score = int(input("Enter a score: "))
    scores.append(score)

total = 0

for index in range(6):
    total = total + scores[index]

average = total / 6

print("Average score:", average)

Common errors to avoid

  • Forgetting to initialise Total to zero.
  • Dividing by the total rather than the number of values.
  • Dividing by the wrong number of elements.
  • Declaring the average as INTEGER when a fractional result may be needed.
  • Calculating the average before all values have been added.
Check the array size: In this example the bounds are [1:6], so there are six elements. If the array size changes, the divisor must also change to the correct number of values.

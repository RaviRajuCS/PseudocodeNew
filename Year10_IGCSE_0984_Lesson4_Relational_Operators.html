Syllabus alignment

Cambridge reference

This lesson follows Cambridge IGCSE (9–1) Computer Science 0984, syllabus for examination in 2026, 2027 and 2028, Topic 8.1.4(f): relational operations.

The six relational symbols are =, <, <=, >, >= and <>. The result of a relational operation is always of data type BOOLEAN.

Scope for today: This lesson covers relational operators only. We will teach AND, OR and NOT in the next lesson, so students can understand and practise one new idea at a time.

Official source: Cambridge 0984 syllabus 2026–2028, pseudocode reference section, relational operations. Open official Cambridge syllabus (PDF).

Learning goals

By the end of this lesson, you should be able to…

Explain what a relational operator does.
Use all six Cambridge relational symbols correctly.

Store a comparison result in a BOOLEAN variable.
Trace relational expressions using given values.
Recognise the differences between Cambridge Pseudocode and Python comparison syntax.
Three-stage learning: Understand the problem → write Cambridge Pseudocode → compare with Python where useful.

Activity 2
10 minutes · Teacher demonstration

How can a computer compare two values?

Problem: A school system needs to check whether a student's mark is at least 50.

Ask students: What value do we need? What comparison should be made? What kind of result will the comparison produce?

// Check whether a student has reached 50 marks
DECLARE StudentMark : INTEGER
DECLARE HasPassed : BOOLEAN

StudentMark ← 67

HasPassed ← StudentMark >= 50

OUTPUT HasPassed
Expected result: TRUE, because 67 is greater than or equal to 50.

Change StudentMark to 42. Ask students to predict the result. It becomes FALSE.

Key concept: A relational operation compares values. Its result is not the difference between the values; it is a Boolean value: TRUE or FALSE.
Core knowledge
Included in the 10-minute demonstration

The six Cambridge relational operators

SymbolMeaningExampleResult
=Equal to7 = 7TRUE
<Less than4 < 9TRUE
<=Less than or equal to5 <= 5TRUE
>Greater than3 > 8FALSE
>=Greater than or equal to6 >= 4TRUE
<>Not equal to10 <> 10FALSE
Do not confuse these symbols: In Cambridge Pseudocode, = means equal to in a comparison. Assignment uses ←. The symbol <> means not equal to.

Store the result in a Boolean variable

DECLARE Temperature : REAL
DECLARE IsHot : BOOLEAN

Temperature ← 31.5
IsHot ← Temperature > 30

OUTPUT IsHot

Expected output: TRUE. The expression Temperature > 30 is evaluated first; its Boolean result is stored in IsHot.

Activity 4
15 minutes · Formal practice

Write and trace relational expressions

For each problem, identify the values, choose suitable variable types, write the Pseudocode and state the Boolean result.

Question 1 · Minimum age

Input a person's age. Store TRUE in CanRegister if the age is 16 or above; otherwise, store FALSE. Display the Boolean result. (Use the relational comparison only; do not use IF yet.)

Show one possible solution
// Check whether the person is at least 16
DECLARE Age : INTEGER
DECLARE CanRegister : BOOLEAN

INPUT Age
CanRegister ← Age >= 16
OUTPUT CanRegister

Question 2 · Stock availability

Input the number of items in stock. Store the result of the comparison Stock <> 0 in a Boolean variable called ItemsAvailable. Display the result.

Show one possible solution
// Check whether any items remain in stock
DECLARE Stock : INTEGER
DECLARE ItemsAvailable : BOOLEAN

INPUT Stock
ItemsAvailable ← Stock <> 0
OUTPUT ItemsAvailable

Question 3 · Temperature comparison

Input two temperatures. Store TRUE in SameTemperature if both values are equal. Display the result.

Show one possible solution
// Compare two temperature readings
DECLARE Temperature1 : REAL
DECLARE Temperature2 : REAL
DECLARE SameTemperature : BOOLEAN

INPUT Temperature1
INPUT Temperature2

SameTemperature ← Temperature1 = Temperature2

OUTPUT SameTemperature

Teacher note: These questions practise relational operations and Boolean assignment only. Do not introduce IF, AND, OR or NOT in this lesson.

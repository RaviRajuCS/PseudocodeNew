1. Recall — Variables and data types

A variable stores one value at a time. For example:

DECLARE Score : INTEGER
Score ← 85

If a program needs to store the marks of 30 students, declaring 30 separate variables would be inconvenient:

Mark1, Mark2, Mark3, ... Mark30

An array provides a more organised way to store a collection of related values under one identifier.

2. Teacher demonstration — What is an array?

An array is a fixed-length data structure that stores a number of elements of the same data type. Each element can be accessed using an index number.

Fixed length
The number of elements is set when the array is declared.
Same data type
All elements in one array have the declared data type.
Index
Each element has a position number used to access it.
One identifier
One array name represents the whole collection.

Visual example — Scores array

Suppose an array named Scores stores five integer marks.

Index 172
Index 285
Index 364
Index 491
Index 578

Scores[1] contains 72. Scores[3] contains 64. Scores[5] contains 78.

Cambridge pseudocode — Declaring a 1D array

DECLARE Scores : ARRAY[1:5] OF INTEGER

Breakdown:

PartMeaning
ScoresIdentifier (name) of the array.
ARRAYDeclares an array data structure.
[1:5]Index range: first index is 1 and last index is 5.
OF INTEGEREvery element stores an INTEGER value.
Cambridge convention: State the lower and upper bounds explicitly. The first index may be 0 or 1; for our examples we will generally use 1, as recommended in the syllabus. Array indices are written inside square brackets. citeturn419357search12

Accessing an individual element

Scores[1] ← 72
Scores[2] ← 85
Scores[3] ← 64

OUTPUT Scores[2]

The output is 85, because the value stored at index 2 is 85.

Changing an element

Scores[3] ← 70

The value at index 3 changes from 64 to 70. The other elements remain unchanged.

3. Index versus value — Do not confuse them

ExpressionMeaningResult / effect
Scores[2]Element at index 2Reads the stored value (85 in our example).
Scores[2] ← 90Assignment to element 2Changes the stored value at index 2 to 90.
Scores[5]Element at index 5Reads the stored value (78 in our example).
Remember: The index identifies the position. The value is the data stored in that position.

What happens if the index is outside the declared range?

For Scores : ARRAY[1:5] OF INTEGER, valid indices are 1, 2, 3, 4 and 5. An attempt to access Scores[0] or Scores[6] is outside the declared range and is an invalid array access.

5. A first look at array input and output

For now, focus on understanding the array and individual elements. In the next lesson, we will use iteration to input values into every element and then process the array.

Here is a short example showing individual input and output operations:

DECLARE Names : ARRAY[1:3] OF STRING

INPUT Names[1]
INPUT Names[2]
INPUT Names[3]

OUTPUT Names[1]
OUTPUT Names[2]
OUTPUT Names[3]

This works, but it becomes repetitive for a large array. An iteration structure can perform the same operation for every index. We will develop that method in the next lesson.

Important distinction: Declaring an array creates its fixed structure. It does not automatically mean that meaningful data has been entered into every element.

Lesson summary

  • An array stores a fixed number of elements of the same data type.
  • Each element is accessed using an index inside square brackets.
  • Declare an array by stating its identifier, index range and data type.
  • Use assignment to change an individual element.
  • Use INPUT and OUTPUT with an indexed element to read and display data.
  • Always stay within the declared index range.

Syllabus alignment

Cambridge reference

This lesson follows Cambridge IGCSE (9–1) Computer Science 0984, syllabus for examination in 2026, 2027 and 2028, Topic 8.1.4(f): logical operations.

Cambridge specifies only three logical operators for this part of the syllabus: AND, OR and NOT. Their operands and results are always of data type BOOLEAN.

Keep the topics separate: This lesson is about logical operators in Pseudocode expressions. It is not the separate Boolean logic topic on drawing and analysing logic-gate circuits. We will also teach selection statements as a separate lesson sequence.

Official source: Cambridge 0984 syllabus 2026–2028, Pseudocode reference, logical operations (PDF).

Activity 2
10 minutes · Teacher demonstration

When does a student qualify?

Problem: A student qualifies for a certificate only if their attendance is at least 90% and their mark is at least 60.

Ask students to identify the two separate comparisons. Each comparison produces a Boolean value. AND combines those Boolean values.

// Check whether a student qualifies
DECLARE Attendance : INTEGER
DECLARE Mark : INTEGER
DECLARE Qualifies : BOOLEAN

Attendance ← 95
Mark ← 72

Qualifies ← (Attendance >= 90) AND (Mark >= 60)

OUTPUT Qualifies
Expected result: TRUE AND TRUE gives TRUE.

Change Mark to 55. Now the expression becomes TRUE AND FALSE, so the result is FALSE.

Key idea: AND and OR combine Boolean values. NOT reverses a Boolean value. These operators do not add or compare numerical values directly.
Core knowledge

The three Cambridge logical operators

AND

TRUE only when both operands are TRUE.

TRUE AND TRUE
Result: TRUE

OR

TRUE when at least one operand is TRUE. It is FALSE only when both are FALSE.

TRUE OR FALSE
Result: TRUE

NOT

Reverses a Boolean value: TRUE becomes FALSE; FALSE becomes TRUE.

NOT TRUE
Result: FALSE

Cambridge Pseudocode examples

// AND: both conditions must be true
IsEligible ← (Age >= 16) AND (Score >= 50)

// OR: at least one condition must be true
NeedsSupport ← (Score < 40) OR (Attendance < 80)

// NOT: reverse a Boolean value
IsNotReady ← NOT IsReady
Operand rule: The operands and results of logical operations are BOOLEAN. In examples such as Age >= 16, the relational comparison is evaluated to produce a Boolean value before AND, OR or NOT is applied.

Python comparison

Cambridge PseudocodePython 3
A AND BA and B
A OR BA or B
NOT Anot A

Python uses lowercase and, or and not. Cambridge Pseudocode writes them in uppercase.

Activity 4
15 minutes · Formal practice

Write and evaluate logical expressions

For each problem, identify the Boolean conditions, write the Cambridge Pseudocode expression, and state the result for the supplied values.

Question 1 · Access requirement

A user may access a resource if their age is at least 13 and their account is active. Input the age and a Boolean value AccountActive. Store the result in CanAccess and display it.

Show one possible solution
// Check the age and account status
DECLARE Age : INTEGER
DECLARE AccountActive : BOOLEAN
DECLARE CanAccess : BOOLEAN

INPUT Age
INPUT AccountActive

CanAccess ← (Age >= 13) AND AccountActive
OUTPUT CanAccess

Question 2 · Support flag

Input a student's mark and attendance percentage. Set NeedsSupport to TRUE if the mark is below 40 or attendance is below 80. Display the result.

Show one possible solution
// Check whether the student needs support
DECLARE Mark : INTEGER
DECLARE Attendance : INTEGER
DECLARE NeedsSupport : BOOLEAN

INPUT Mark
INPUT Attendance

NeedsSupport ← (Mark < 40) OR (Attendance < 80)
OUTPUT NeedsSupport

Question 3 · Reverse a Boolean value

Input a Boolean variable called IsClosed. Store the opposite value in IsOpen. Display IsOpen.

Show one possible solution
// Reverse the closed status
DECLARE IsClosed : BOOLEAN
DECLARE IsOpen : BOOLEAN

INPUT IsClosed
IsOpen ← NOT IsClosed

OUTPUT IsOpen

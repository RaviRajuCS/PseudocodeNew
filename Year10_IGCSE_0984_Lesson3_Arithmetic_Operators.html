Syllabus alignment

Cambridge reference

This lesson is aligned to Cambridge IGCSE (9–1) Computer Science 0984, syllabus for examination in 2026, 2027 and 2028, Topic 8.1.4(f): arithmetic operators.

The arithmetic operators specified are: +, −, /, *, ^, MOD and DIV. The official pseudocode reference explains DIV and MOD using the forms DIV(identifier1, identifier2) and MOD(identifier1, identifier2).

Exam-year reminder: This is the 2026–2028 pseudocode pathway. The 2029–2031 syllabus removes pseudocode and uses Python 3. Confirm the examination year for the class before using this sequence as its exam preparation route.
Learning goals

By the end of this lesson, you should be able to…

Use the seven arithmetic operators required by the syllabus.

Activity 2
10 minutes · Teacher demonstration

Start with a real problem

Problem: A student buys 4 notebooks. Each notebook costs 12.50. Calculate the total cost.

Ask students: What information do we know? What calculation is needed? Which variables should we declare?

// Calculate the total cost of notebooks
DECLARE Quantity : INTEGER
DECLARE UnitPrice : REAL
DECLARE TotalCost : REAL

Quantity ← 4
UnitPrice ← 12.50

TotalCost ← Quantity * UnitPrice

OUTPUT TotalCost
Expected output: 50.0 (the numeric value is fifty; the displayed formatting may vary).

Ask students to identify the multiplication operator and explain why UnitPrice is REAL while Quantity is INTEGER.

Understand DIV and MOD together

10 divided by 3 gives a quotient of 3 and a remainder of 1.

DIV(10, 3) = 3

How many complete groups of 3 can be made from 10?

MOD(10, 3) = 1

How many are left over after making those complete groups?

Cambridge notation: Use DIV(Identifier1, Identifier2) and MOD(Identifier1, Identifier2). The identifiers used as operands are INTEGER. Do not replace these with Python symbols in a Cambridge Pseudocode answer.

Example using declared integer variables

DECLARE NumberA : INTEGER
DECLARE NumberB : INTEGER
DECLARE Quotient : INTEGER
DECLARE Remainder : INTEGER

NumberA ← 10
NumberB ← 3

Quotient ← DIV(NumberA, NumberB)
Remainder ← MOD(NumberA, NumberB)

OUTPUT Quotient
OUTPUT Remainder

Python comparison

Cambridge PseudocodePython 3
A + BA + B
A - BA - B
A * BA * B
A / BA / B
A ^ BA ** B
DIV(A, B)A // B for positive integer operands
MOD(A, B)A % B for positive integer operands
Important Python difference: Python uses ** for powers; ^ in Python is not exponentiation. Also, Python floor division with negative numbers can behave differently from Cambridge's description of discarding the fractional part. Our direct DIV/MOD comparisons here use positive integers.

Activity 4
15 minutes · Formal practice

Write the algorithm

For each task, identify the inputs, choose suitable data types, write the Cambridge Pseudocode, and check your calculations.

Question 1 · Perimeter

Input the length and width of a rectangle. Calculate and display its perimeter.

Show one possible solution
// Calculate the perimeter of a rectangle
DECLARE Length : REAL
DECLARE Width : REAL
DECLARE Perimeter : REAL

INPUT Length
INPUT Width

Perimeter ← 2 * (Length + Width)

OUTPUT Perimeter

Question 2 · Complete groups and remainder

Input the number of students and the number of students in each group. Display how many complete groups can be formed and how many students remain. Assume both inputs are positive integers and the group size is greater than zero.

Show one possible solution
// Find complete groups and students remaining
DECLARE NumberOfStudents : INTEGER
DECLARE GroupSize : INTEGER
DECLARE CompleteGroups : INTEGER
DECLARE StudentsLeft : INTEGER

INPUT NumberOfStudents
INPUT GroupSize

CompleteGroups ← DIV(NumberOfStudents, GroupSize)
StudentsLeft ← MOD(NumberOfStudents, GroupSize)

OUTPUT CompleteGroups
OUTPUT StudentsLeft

Question 3 · Calculate a final price

Input the price of an item and the number of items purchased. Calculate the total price. Then calculate a discount equal to 10% of the total and display the discount and the amount to pay.

Show one possible solution
// Calculate a 10 percent discount and final price
DECLARE UnitPrice : REAL
DECLARE Quantity : INTEGER
DECLARE TotalPrice : REAL
DECLARE Discount : REAL
DECLARE AmountToPay : REAL

INPUT UnitPrice
INPUT Quantity

TotalPrice ← UnitPrice * Quantity
Discount ← TotalPrice * 0.10
AmountToPay ← TotalPrice - Discount

OUTPUT Discount
OUTPUT AmountToPay

Teacher note: Accept equivalent correct expressions. Ensure students use Cambridge operators and meaningful identifiers. Do not require selection or iteration in this lesson.

Activity 2
10 minutes · Teacher demonstration

What is a variable?

Imagine a labelled box in the computer's memory. The label is the variable name; the value is the information stored inside it. The value can change while the algorithm runs.

Variable name

Score – the label used to refer to the stored value.

Value

75 – the current information stored in the variable.

Data type

INTEGER – describes what kind of value the variable is intended to store.

Declare a variable

DECLARE Score : INTEGER

This declares a variable named Score with the data type INTEGER.

Assign and change a value

DECLARE Score : INTEGER

Score ← 10
Score ← 15
Score ← Score + 5

OUTPUT Score

Ask students to predict the final output. It is 20: the second assignment replaces 10 with 15, and the third adds 5 to the current value.

Initialisation

Initialising means giving a variable its first value before it is used. For example:

DECLARE Attempts : INTEGER
Attempts ← 0
Important: DECLARE introduces the variable and its type. Assignment gives the variable a value. Do not assume that declaring a variable automatically gives it a useful starting value.

Variable naming habits

  • Choose meaningful names, such as StudentAge or TotalMark.
  • Use letters and digits sensibly; begin a name with a letter.
  • Avoid spaces and punctuation in identifiers.
  • Use the same spelling consistently throughout the algorithm.
  • Follow the naming rules and conventions used by your course or pseudocode environment.

Meet the five data types

Data typeWhat it representsExample valueThink of…
INTEGERWhole numbers, with no fractional part25, -8, 0Number of students
REALNumbers that can have a fractional part15.75, -2.5Temperature or price
CHARA single character'A', '7', '?'One initial or symbol
STRINGA sequence of characters"Ravi", "Year 10"A name or message
BOOLEANOne of two logical valuesTRUE or FALSEWhether a condition is true
Watch the difference: 7 is an INTEGER, while '7' is a CHAR. The value's meaning and representation matter, not just what it looks like.

Try a declaration for each type

DECLARE NumberOfBooks : INTEGER
DECLARE Temperature : REAL
DECLARE Initial : CHAR
DECLARE StudentName : STRING
DECLARE IsPresent : BOOLEAN

Python comparison

Python does not use a DECLARE statement. A variable is created when a value is assigned. Python also uses str for text and bool for Boolean values.

Python input reminder: Python's input() returns text. Convert it when a numeric value is needed, for example Age = int(input("Enter age: ")) or Price = float(input("Enter price: ")).

15 minutes · Formal practice

Write the Cambridge Pseudocode

For each problem: identify the information needed, choose suitable data types, declare variables, then write the algorithm. Add meaningful comments.

Question 1 · Student profile

Input a student's name, age and whether the student is present. Display all three values.

Show one possible solution
// Input and display a student's details
DECLARE StudentName : STRING
DECLARE Age : INTEGER
DECLARE IsPresent : BOOLEAN

INPUT StudentName
INPUT Age
INPUT IsPresent

OUTPUT StudentName
OUTPUT Age
OUTPUT IsPresent

Question 2 · Product price

Input the price of a product and the quantity purchased. Calculate and display the total cost.

Show one possible solution
// Calculate the total cost of a purchase
DECLARE UnitPrice : REAL
DECLARE Quantity : INTEGER
DECLARE TotalCost : REAL

INPUT UnitPrice
INPUT Quantity

TotalCost ← UnitPrice * Quantity

OUTPUT TotalCost

Question 3 · Update a score

Declare an integer variable called Score. Initialise it to 0. Add 10, then add 5. Display the final score.

Show one possible solution
// Initialise and update the score
DECLARE Score : INTEGER

Score ← 0
Score ← Score + 10
Score ← Score + 5

OUTPUT Score

Final output: 15.

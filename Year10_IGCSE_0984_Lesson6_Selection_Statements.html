Lesson 6: Selection Statements

Learning outcomes

By the end of this lesson, you should be able to:

  • Explain why an algorithm sometimes needs to make a decision.
  • Use IF…THEN…ENDIF for a one-way decision.
  • Use IF…THEN…ELSE…ENDIF for a two-way decision.
  • Use a Boolean condition based on relational and logical operators.
  • Trace the statements that execute for different input values.
Lesson boundary: Today we learn simple IF and IF…ELSE selection. Nested selection and CASE are deliberately left for later lessons.

2. Teacher demonstration – 10 minutes

Why do we need selection?

A sequential algorithm executes instructions in order. A selection statement allows the algorithm to choose which instruction or group of instructions to execute, depending on whether a condition is TRUE or FALSE.

A. One-way selection: IF…THEN…ENDIF

IF <condition> THEN <statements> ENDIF

Example: Display a message only when the temperature is above 30.

INPUT Temperature IF Temperature > 30 THEN OUTPUT "It is a hot day" ENDIF OUTPUT "Program finished"

If Temperature is 35, the message “It is a hot day” is displayed. If Temperature is 25, the condition is FALSE, so the statement inside the IF is skipped. The program continues after ENDIF.

B. Two-way selection: IF…THEN…ELSE…ENDIF

IF <condition> THEN <statements if TRUE> ELSE <statements if FALSE> ENDIF

Example: Decide whether a student has reached the pass mark.

INPUT Mark IF Mark >= 50 THEN OUTPUT "Pass" ELSE OUTPUT "Not yet passed" ENDIF
Remember: Exactly one branch of an IF…ELSE statement is executed. If the condition is TRUE, the THEN branch runs. Otherwise, the ELSE branch runs. Execution then continues after ENDIF.

Python equivalent (comparison)

mark = int(input("Enter mark: ")) if mark >= 50: print("Pass") else: print("Not yet passed")

Python uses lowercase if and else, a colon, and indentation. Cambridge Pseudocode uses THEN, ELSE and ENDIF.

A condition is an expression that evaluates to a Boolean value: TRUE or FALSE. A condition can include relational operators and, where needed, logical operators.

Try a combined condition

IF Mark >= 50 AND Attendance >= 80 THEN OUTPUT "Eligible" ELSE OUTPUT "Not eligible" ENDIF

Both requirements must be TRUE for the student to be eligible.

4. Formal practice – 15 minutes

Complete the three tasks. Write Cambridge Pseudocode using the correct structure and indentation.

Task 1 – One-way decision

Input a person's age. If the age is 18 or above, output "Adult". If the condition is FALSE, do not display an age-category message.

INPUT Age IF Age >= 18 THEN OUTPUT "Adult" ENDIF

Task 2 – Two-way decision

Input an integer. Use IF…ELSE to output "Even" if the number is divisible by 2; otherwise output "Odd". Use MOD.

INPUT Number IF MOD(Number, 2) = 0 THEN OUTPUT "Even" ELSE OUTPUT "Odd" ENDIF

Task 3 – Combined condition

Input a test mark and attendance percentage. Output "Award eligible" only if the mark is at least 70 AND attendance is at least 90. Otherwise output "Not eligible".

INPUT Mark INPUT Attendance IF Mark >= 70 AND Attendance >= 90 THEN OUTPUT "Award eligible" ELSE OUTPUT "Not eligible" ENDIF

Suggested answers are for checking after you have attempted each task. Equivalent correct solutions are acceptable.

Teacher checkpoint

  • Students can explain TRUE and FALSE outcomes.
  • Students distinguish one-way IF from two-way IF…ELSE.
  • Students use THEN, ELSE and ENDIF in the correct places.
  • Students trace boundary values such as 49, 50 and 51.
  • Students use AND only when both conditions must be satisfied.

Lesson 12: FOR Loops – Counters, Totals and Averages

2. Teacher demonstration – 10 minutes

A. Counter – count how many times something happens

A counter is a variable that is increased when an event or condition occurs. It keeps track of how many times that event has happened.

PassCount ← 0 FOR Student ← 1 TO 5 INPUT Mark IF Mark >= 50 THEN PassCount ← PassCount + 1 ENDIF NEXT Student OUTPUT PassCount

Each mark is entered once. If the mark is 50 or more, PassCount increases by one. The final output is the number of students who passed.

B. Accumulator – calculate a running total

An accumulator stores a value that is updated repeatedly, usually by adding a new value to the existing total.

Total ← 0 FOR Count ← 1 TO 5 INPUT Score Total ← Total + Score NEXT Count OUTPUT Total
Why initialise Total to 0? The first value is added to a known starting value. Without initialisation, the calculation would not have a reliable starting point.

C. Calculate an average

Average = Total ÷ Number of values. The total is accumulated during the loop; the average is calculated after all values have been processed.

Total ← 0 FOR Count ← 1 TO 5 INPUT Score Total ← Total + Score NEXT Count Average ← Total / 5 OUTPUT Average

Python comparison

total = 0 pass_count = 0 for student in range(1, 6): mark = int(input("Enter mark: ")) total = total + mark if mark >= 50: pass_count = pass_count + 1 average = total / 5 print("Total:", total) print("Average:", average) print("Number of passes:", pass_count)

The Python example uses the same logic. Python's range stop value is exclusive, so range(1, 6) repeats for student values 1 to 5.

4. Formal practice – 15 minutes

Write each solution in Cambridge Pseudocode. Initialise counters and totals before the FOR loop.

Task 1 – Count positive numbers

Input 8 integers. Count how many are greater than zero. Display the count after all 8 numbers have been entered.

PositiveCount ← 0 FOR Count ← 1 TO 8 INPUT Number IF Number > 0 THEN PositiveCount ← PositiveCount + 1 ENDIF NEXT Count OUTPUT PositiveCount

Task 2 – Total the prices

Input the prices of 6 items. Calculate and display the total cost.

Total ← 0 FOR Item ← 1 TO 6 INPUT Price Total ← Total + Price NEXT Item OUTPUT Total

Task 3 – Calculate the average mark

Input 10 test marks. Calculate and display the average mark.

Total ← 0 FOR Student ← 1 TO 10 INPUT Mark Total ← Total + Mark NEXT Student Average ← Total / 10 OUTPUT Average

Task 4 – Count passes and calculate total

Input 5 student marks. Calculate the total of the marks and count how many students passed (mark at least 50). Display both results.

Total ← 0 PassCount ← 0 FOR Student ← 1 TO 5 INPUT Mark Total ← Total + Mark IF Mark >= 50 THEN PassCount ← PassCount + 1 ENDIF NEXT Student OUTPUT Total OUTPUT PassCount

Complete your own solution before revealing the suggested answer. Make sure the total and counter are initialised before the loop begins.
